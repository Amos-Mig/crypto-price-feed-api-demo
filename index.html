What's inside

Multi-exchange aggregation

Polls public Coinbase, Kraken and Binance endpoints, computes a consensus price per pair and tags every response with its sources.

15s response cache

Each pair is cached with a per-pair TTL, so repeat reads come back in single-digit ms and exchange rate limits are never touched. Watch X-Cache flip above.

Single-file Python

One small file, no framework, no queue. Drop it on a cheap VPS or a free tier, run it, point your dashboards at it.

  "data": {
    "BTC": { "price": 67382.11, "quote": "USD", "change_24h": -0.84,
             "sources": ["coinbase", "kraken", "binance"] },
    "ETH": { "price": 3284.97, "quote": "USD", "change_24h": 1.62,
             "sources": ["coinbase", "kraken", "binance"] }
  },
  "cached": true
}
import requests, time

FEED   = "http://vps:8080"
WATCH  = ["BTC", "ETH", "SOL"]

while True:
    r = requests.get(f"{FEED}/v1/prices",
        params={"symbols": ",".join(WATCH)}).json()
    print({k: v["price"] for k, v in r["data"].items()})
    time.sleep(15)  # cache TTL — zero rate-limit pressure
